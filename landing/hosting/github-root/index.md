# Native Sheets

Native Sheets is a free macOS app for opening and editing `.xlsx` spreadsheet files. It is a standalone editor for people who need to work with a workbook without installing Microsoft Excel.

[Visit Native Sheets and download the app](/nativesheets/)

## Choose the right way to open a workbook

Use the Mac app when you want to edit a workbook and save an `.xlsx` file. If you just want to inspect a spreadsheet, the [free browser viewer](/nativesheets/viewer/) reads the file on your device without uploading it. The viewer is for reading data, not editing and saving an Excel workbook.

Spreadsheet compatibility matters. A workbook can contain formulas, charts, pivot tables and other parts that an editor does not fully understand. The guides explain what Native Sheets supports and where you should be careful before relying on a changed file.
